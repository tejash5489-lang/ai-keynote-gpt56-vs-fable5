Both labs converged on nearly the same five rungs. OpenAI added a sixth, different axis — parallel agents, not deeper thought. Anthropic keeps multi-agent work one layer up, in the harness (Claude Code / Managed Agents).

On Claude, effort shapes all token spend — text, tool calls, and thinking — not just a reasoning budget. Anthropic's API default is high, not low. On GPT-5.6, effort levels are a single-agent thinking dial; Ultra is a separate, harness-level mode that runs four agents at once and is not selectable as a 6th "deeper" effort value.

Off the benchmark, on the record.

Opinion and community findings — not official scores.

OPINION

Community framing that circulated around the Sol launch: Fable 5 plans and delegates across multi-day runs like a manager; Sol executes fast and cheap like a worker. Not an official claim from either company — kept here labeled as opinion, not fact.

PRODUCT REALITY

Sol's spec says 1.05M tokens of context. In practice, OpenAI's Codex product quietly cut the working context from 372K → 272K → 258K after user complaints — a product limit, not a model limit. Anthropic keeps Fable 5's full 1M window in its Cowork product, and rations by other means instead.

METHODOLOGY

Vendors pick the harness that flatters them. Fable 5's headline SWE-bench Pro number used Anthropic's own scaffolding; Sol's headline numbers on Terminal-Bench and Agents' Last Exam are OpenAI's own launch-day claims. A vendor benchmark is a marketing artifact until someone neutral reruns it.

There is no universal winner.

Cheapest agentic coding at scale SOL / TERRA / LUNA
Higher raw intelligence, longest autonomous runs FABLE 5
Effort ladder Nearly identical five rungs — OpenAI bolts on parallel-agent Ultra; Anthropic leaves that to the harness

Coding-heavy, cost-sensitive, high-volume agents → GPT-5.6 Terra or Luna. Hardest single agentic-coding runs → Sol, cheaper than Fable 5 at similar Coding Agent Index scores.
